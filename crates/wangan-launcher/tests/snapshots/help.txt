wangan-launcher — Wangan Midnight arcade series

  wangan-launcher                          open the window (games, settings, controls)
  wangan-launcher --library <folder>       add a folder with your games (repeatable)
  wangan-launcher --list                   list the games found and their state
  wangan-launcher --check [<game>]         check a game (or all) can start, without starting
  wangan-launcher --play <game> [options]  start a game (wangan-r, mt1, mt3, mt3dxp, mt5, mt5dxp, mt6, mt6r, mt6rr)
  wangan-launcher --set <game> <options>   save options for a game without starting it (also --game)

Options (saved in that game's settings):
  --look original|recommended|steam_deck  Look
  --output <WxH>                          Output size (Linux helper)
  --upscaler fsr|nis|linear|nearest       Upscaler (Linux helper)
  --sharpness <0-20>                      Sharpness (Linux helper)
  --fullscreen on|off                     Fullscreen (Linux helper)
  --render <WxH|native>                   Game render size
  --deadzone <0.00-0.30>                  Dead zone

Test options for --play:
  --headless               run in an invisible display
  --no-input               no controller input
  --input-script <file>    timed inputs, into the input block (not Wangan R)
  --seconds <n>            stop the game after n seconds

  wangan-launcher --help                   this text

Board files:
  wangan-launcher --add-files <path>  look in a folder or zip for the files Wangan Midnight R and Maximum Tune need
